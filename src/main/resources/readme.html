SWRLTab

Protégé Desktop plugin for working with the SWRL rule and SQWRL query languages. The plugin provides two tabs: the SWRLTab, which can be used to manage SWRL rules, and the SQWRLTab, which works with SQWRL queries. The tabs can be activated via the "Window → Tabs" menu item.

Please refer to the wiki for language reference documentation. For this development branch, see the build guide and built-in registration guide.

Protégé 6 development build

The 2.1.5-SNAPSHOT compatibility branch targets Protégé 6.0.0-alpha-1 and OWLAPI 5.5.1. It is validated on JDK 17 and is not a Protégé 5 update. The SWRLTab and SQWRLTab support contributed built-in libraries through the swrltab-plugin.SWRLBuiltInLibraryFactoryPlugin extension point.

This development build has not been published as a release. Use the locally built plugin jar with the matching Protégé 6 host.
